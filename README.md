# Linux Password Cracking using John the Ripper

## Objective
To simulate cracking Linux system passwords using passwd and shadow files.

## Tools Used
- Kali Linux
- John the Ripper
- rockyou.txt

## Methodology
1. Created passwd and shadow files
2. Combined using unshadow
3. Performed dictionary and rule-based attacks

## Results
- Weak passwords cracked successfully
- Strong passwords resisted cracking

## Conclusion
Even strong hashing (SHA-512) is vulnerable if weak passwords are used.
